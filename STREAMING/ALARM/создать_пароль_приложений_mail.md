# как создать пароль приложений

Чтобы создать пароль приложений для отправки сообщений из скрипта Python через почту mail.ru, нужно сделать следующее:

- Войдите в свой почтовый ящик на сайте mail.ru.

- Перейдите в «Настройки» → «Все настройки» → раздел «Безопасность».

- Найдите пункт «Пароли для внешних приложений» и выберите его.

- Нажмите кнопку «Добавить» для создания нового пароля.

- Введите название для пароля (например, название вашего скрипта или приложения).

- Подтвердите создание пароля, возможно, потребуется ввести пароль от аккаунта.

- Скопируйте сгенерированный пароль — это и есть ваш специальный пароль приложений.

- Используйте этот пароль в вашем Python-скрипте вместо основного пароля для SMTP-авторизации.

Пароль приложений нужен, чтобы обеспечить безопасность вашего аккаунта, позволяя сторонним программам получать доступ к почте без передачи основного пароля и с возможностью быстрой отмены доступа.
