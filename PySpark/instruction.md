#### Определения
RDD (Resilient Distributed Datasets) - это неизменяемая распределённая совокупность элементов ваших данных, которые могут храниться в памяти или на диске в кластере машин.
- это абстракция набора данных, состоящего из записей одного произвольного типа и разделенного на части, которые размещены по всему кластеру. 

DataFrame - это абстракция, построенная поверх RDD. Он представляет собой распределенную коллекцию строк с именованными столбцами,  похожей  на таблицу в реляционной базе данных или таблицу в Excel.

Dataset API - Это коллекция сильно типизированных JVM-объектов, сочетающая оптимизацию DataFrame с безопасностью типов RDD. Но Dataset API недоступен в PySpark.
